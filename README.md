# مراجعة التجارب العملية — مقرر 103 فيز (جامعة الملك سعود)

بوابة تعليمية تفاعلية لمراجعة التجارب العملية لمقرر **الفيزياء العامة (103 فيز)** — كلية العلوم، قسم الفيزياء والفلك، جامعة الملك سعود.

## التجارب المشمولة (جميع التجارب العشر المقررة)

1. **قانون هوك (Hooke's Law)** — المرونة وإيجاد ثابت النابض ($k$)
2. **قانون بويل (Boyle's Law)** — دراسة الغازات وحساب الضغط الجوي ($P_0$)
3. **السقوط الحر (Free Fall)** — قياس تسارع الجاذبية الأرضية ($g$)
4. **معامل اللزوجة (Viscosity / Stokes)** — تعيين معامل اللزوجة لسائل لزج ($\eta$)
5. **طاولة القوى (Force Table)** — إيجاد محصلة قوتين عملياً وبيانياً وتحليلياً ($R, \theta_R$)
6. **معامل يونج (Young's Modulus)** — تعيين معامل يونج لسلك معدني بطريقة سريل ($Y$)
7. **العربة الهوائية (Air Track)** — مردود الطاقة ونسبة الطاقة المفقودة
8. **الحرارة النوعية (Specific Heat)** — التوازن الحراري وتعيين الحرارة النوعية لكرة صلبة ($C_b$)
9. **مكافئ جول (Joule's Equivalent)** — مبدأ حفظ الطاقة والمكافئ الميكانيكي للحرارة ($J$)
10. **سرعة الصوت (Speed of Sound)** — الرنين في الأعمدة الهوائية المغلقة ($v, v_T$)

## المميزات

- **شرح نظري وعملي متكامل** مستند إلى مذكرة التجارب وحلول التقارير المعتمدة.
- **عروض فيديو عملية مضمنة** لكل تجربة من التجارب العشر.
- **طباعة رياضية دقيقة عبر LaTeX (KaTeX)** وخط عربي واضح (**Tajawal**).
- **مدرب الجداول والوحدات والتحويلات** لجميع التجارب.
- **نموذج تقييم تفاعلي** يحاكي هيكلة الاختبار العملي مع إمكانية الطباعة.
- **مصفوفة مقارنة شاملة** لجميع القوانين والمحاور والوحدات.
